# Home Assistant Frigate integration: HTTP basic auth through an Authentik proxy, credentials in the URL

<!-- minutiae entry format 2 -->

## Human

**Submission**

> The Home Assistant HACS integration for Frigate can auth through an Authentik reverse proxy with HTTP basic auth (assuming you've got Authentik configured to read/strip HTTP basic auth). Don't set user/pass in the HA config dialog for Frigate, but instead use the standard "https://user:pass@frigate.domain" syntax.
